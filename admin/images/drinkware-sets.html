Drinkware sets ​

Drinkware set is enhanced record of corresponding image map. Drinkware set allow to assign localized labels and weights to each of the object defined in Image map record.

Properties ​

  • Drinkware set ID - Unique string within drinkware set records

  • Description - Free text to describe the drinkware set

  • Image map - Select existing image map record to create new guide image

Deletion ​

Make sure that drinkware set is not assigned to any of the portion size methods.
